Organizer Mod installation
==========================

1. Close PKHeX.
2. Extract this ZIP into the directory containing PKHeX.exe.
3. Preserve the included plugins/OrganizerMod/ directory structure.
4. Start PKHeX and choose Tools > Organizer Mod.

Organizer Mod is early-development software. Test it only with copied save files.
Type-Optimized Box Allocation always shows a complete preview before applying changes
and does not save the edited save file to disk automatically.
Its optional matching backgrounds are disabled by default and, when supported by
the loaded game, are included in the same preview and rollback-protected operation.
Living Dex Sorting preserves duplicates in overflow, reports missing entries, and
uses the same preview, confirmation, snapshot, and rollback safeguards.
PKM Database Import can optionally compare same PIDs with Team and Pension Pokémon;
Pension is read-only, while explicit opt-ins can replace matching Team members or
use free Team slots before selected boxes.
Its species matching can keep shiny/non-shiny groups separate or combine them, and
the database scan can be filtered to shiny-only or non-shiny-only Pokémon.
Remove Duplicates by PID scans the party, every box, and read-only pension storage,
and previews every keep/remove decision before clearing matching PID/species copies.
This package intentionally does not contain PKHeX or PKHeX.Core assemblies.
