Organizer Mod installation
==========================

1. Close PKHeX.
2. Extract this ZIP into the directory containing PKHeX.exe.
3. Preserve the included plugins/OrganizerMod/ directory structure.
4. Start PKHeX and choose Tools > Organizer Mod.

Organizer Mod is early-development software. Test it only with copied save files.
This package intentionally does not contain PKHeX or PKHeX.Core assemblies.
